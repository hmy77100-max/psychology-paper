# Analysis registry

Record only analysis specifications and results adopted by the user. Candidate methods, rejected scoring rules, exploratory retries, and full conversation history do not belong here.

# Reproducibility requirement

Each adopted analysis records its data source, scoring, sample, exclusions, model, software and version, estimation settings, Bootstrap settings, random seed when applicable, formal output, and manuscript synchronization locations.
