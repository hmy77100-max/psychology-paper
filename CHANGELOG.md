# Changelog

## 0.5.0 — 2026-10-07

- Add optional manifest-bound resource stage plans, canonical cross-stage deduplication and explicit same-context read attestations; keep the 12,000-character body budget and whole-resource groups.
- Separate argument, resolution, capacity and read-receipt failures; add regression coverage for the observed three-supplement overflow and complete staged CLI journeys. Read coverage is not comprehension or manuscript verification; see `docs/validation/resource-stages.md`.

- Add focused prose diagnostics, over-editing protections, evidence-aware contribution wording and author-sample observations within the existing candidate workflow.
- Add configurable, explicitly invoked collaboration perspectives without a default multi-agent panel; preserve evidence-based dissent and researcher decisions.
- Clarify item-level partial approval, rejection, intentional holds, supersession, save receipts and cumulative decision recovery in existing project records.
- Require task-scoped requirement-to-candidate verification, including relevant cross-section and bilingual dependencies; structural checks do not establish scientific correctness.
- Preserve source manuscripts and data. Installation is a separate explicit step; see `docs/validation/writing-collaboration.md` and `docs/validation/resource-stages.md` for pre-release verification scope and limits.

## 0.4.0 — 2026-09-30

- Enforce complete three-part candidate artifacts with actual source/extraction hashes and logical-unit spans; keep unrestricted author replies and candidate-only manuscript boundaries.
- Add read-only full-revision preflight, body/abstract/keywords stage checks, proposed approval transitions, current-baseline budget checks and dependent-section invalidation.
- Add exact keyword routing, focused literature support, author-led journal contribution planning and task-scoped bilingual freshness checks.
- Prioritize introduction evidence for the research-question/hypothesis chain; recommend citations for incremental argumentative value, not volume.
- Preserve and extend current-manuscript authority, deep-review coverage, competing explanations and prioritized repair advice.
- Add complete resource cost diagnostics, selector inventory, canonical deduplication and hash-based reuse guidance without raising the 12,000-character default budget.
- Add synthetic regression journeys and cross-platform CI. No private manuscript materials, background watchers, automatic translation approval, source-document writes or installation-cache updates.

Validation scope and outstanding live-agent acceptance are documented in `docs/validation/author-led-workflow.md`. Automated structural/state checks do not prove scientific quality, token savings or immunity to long-run execution drift.

## 0.3.0 — 2026-09-19

- Extend read-only review with targeted external evidence verification and explicit source/access boundaries.
- Add design-aware methods review, contribution/target-journal comparison, and resource-sensitive revision options.
- Add bounded quality review, duplicate/conflict reconciliation, and evidence-based issue closure/reopening.
- Reuse confirmed journal/article context and existing memory without repeated positioning or automatic state creation.
- Preserve the short review route and separate advice from editing/analysis execution.
- Add optional read-only evidence/issue record checkers; structural completeness does not establish scientific correctness.

Validated with 108 automated tests and documented synthetic scenarios. These checks do not establish improved acceptance rates or long-run scientific reliability.
