# Research design taxonomy

Classify a paper on independent axes. Do not force every quantitative paper into one type.

## Paper type

`empirical-quantitative`, `empirical-qualitative`, `mixed-methods`, `review`, `meta-analysis`, `scale-development`, `methodological`, `theoretical`.

## Design tags

Select every applicable tag: `survey`, `behavioral-experiment`, `instrument-based`, `cross-sectional`, `longitudinal`, `intensive-longitudinal`, `within-subject`, `between-subject`, `factorial`, `quasi-experimental`, `multilevel`, `behavioral-task`, `psychophysiology`, `eye-tracking`, `EEG`, `neuroimaging`.

## Observation unit

Record whether rows represent participants, trials, stimuli, dyads, groups, measurement occasions, documents, or effect sizes. Add nesting and repeated-measure levels separately.

## Evidence source

Record self-report, informant report, interview, observation, behavioral choice, task performance, consequential behavior, physiological signal, neural signal, archival record, or published effect.

## Measurement technology

Record the scale, task, device, acquisition system, software, and derived feature when each changes interpretation. A device output is not automatically identical to the psychological construct used to interpret it.

The selected tags control which audit fragments load. Survey work does not inherit experimental manipulation checks; qualitative work does not inherit quantitative parameter checks.
