# Analysis registry schema

An adopted analysis entry records a stable analysis ID, research question, design tags, observation unit, variable-field map, scoring, sample, exclusions, model, covariates, estimator, software and version, Bootstrap settings, random seed, authoritative output, optional verification output, discrepancy status, user-adoption status, and manuscript synchronization locations.

Candidate methods and rejected specifications stay outside the registry. An adopted result may have one authoritative source and at most one verification source.
