# Source comparison

Compare sources on the same scientific specification: data version, scoring, sample, exclusions, model, covariates and estimator. Check relevant settings and seeds for comparability; record software and output location as execution provenance, allowing different verification implementations and artifact locations. Report confirmed causes separately from hypotheses. Do not merge F, p, degrees of freedom, effect size, confidence interval, or simple effects from different analysis identities.

Separate scripts using the same numerical library are same-engine reproduction, not an independent numerical reference. When a legacy output lacks the modern contract, state which recorded fields were actually checked and which were newly calculated; a manual field comparison is not a successful structured alignment.
