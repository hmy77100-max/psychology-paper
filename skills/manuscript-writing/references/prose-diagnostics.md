# Prose diagnostics

按当前逻辑单元的任务诊断，只处理实际问题。保持完整原文、候选及必要说明的既定顺序；原文逐字完整，不用“见原文/上文/以所给段落为底稿”代替。不固定排版段数，不额外强制长审计。

## Observed phrase → problem → Repair

| 观察到的表达 | 有依据的修法 |
| --- | --- |
| “具有重要意义”“揭示复杂性” | 写清具体问题及获支持的contribution；缺乏依据时标记missing support，不虚构价值。 |
| “首次全面证明” | 对照已核验直接前作和证据上限，写明具体差异；新样本本身不等于首次。 |
| “大量研究”“相对较好” | 补清实际来源、比较对象、指标和条件，不编造数量或效果。 |
| “近年来备受关注” | 进入本单元真实问题，不制造全领域空白。 |
| 机械连接、强凑三点、反复“不仅”、句尾拔高 | 保留真实递进或对比，删除无作用的包装。 |
| 泛化贡献清单、引用堆砌 | 说明每项贡献和引文的论证作用；no citation quota，不自动删除引用。 |
| 多层长句、“值得强调” | 拆分独立观点，保留必要条件与推理关系，由内容承担强调。 |

示例（非真实研究事实）：
原句：“此外，本研究具有重要意义，进一步揭示了这一问题的复杂性。”
诊断：未指出具体增量。
候选：“本研究将已有的相关性问题推进到条件差异问题。”
使用条件：作者已确认此贡献，且实际设计、结果和已核验前作支持此推进；否则保留有支持的结果，将贡献缺口放必要说明，不把示例当作事实补入。

## 保留有效表达

保留evidence-tied uncertainty，如“提示”“可能”“与……一致”；它不同于没有对象的含糊限定。保留准确术语、必要重复、定义、公式、符号、合宜被动语态与作者有功能的表达。纯润色保持全部数字、结果、引用；事实纠正另走核验与授权。

不设统一禁词、破折号禁令、句长阈值、第一人称规则或引用限额。按语言、期刊、语境判断。保留statistical reporting：不把均值改成范围，不补造检验、显著性或机制。弱化动词不能填补缺失证据；科学主张变动交证据审计，核心论据缺口继续已有授权的文献支持。

## 作者声音

以latest author-edited版本和author sample为依据，观察sentence rhythm、连接习惯、hedge placement、开头方式、符号和惯用表达。样文事实不移植到当前稿，也不模仿样文错误。没有样文时采用清晰正式表达，不虚称学会作者风格。

例如样文以问题开头、短句对比：可在当前单元功能适合时采用，不推广为每段必须设问。将观察依据和重要修改原因放必要说明。

永久偏好进入既有STYLE_DELTA须explicit approval；临时措辞留在当前任务，观察不等于批准。不开平行语料库，不把本流程用于规避AI披露或基金申请书。
