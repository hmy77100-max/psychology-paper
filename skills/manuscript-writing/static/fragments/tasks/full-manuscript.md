# Full-manuscript writing

Use only in project mode after journal positioning and evidence audit. The default revision sequence is `Body sections → Abstract → Keywords`; revise the title when the user requests it or when the submission framing is finalized. Process each body section, the abstract, and the keywords as separate approved units. Carry forward only the current authoritative mainline and approved constraints.

Never output the entire source, full revision, and full translation at once. Chunk by section or subsection, track completed units in project state, and avoid regenerating approved sections after a local change.
