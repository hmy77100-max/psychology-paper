# Methods

Use when writing participants, design, materials, procedure, measures, ethics, or analysis. Report reproducible facts: recruitment, sample flow, factors and levels, randomization, task sequence, scoring, exclusions, missing data, software/model, and approvals when supplied.

Name manipulations, checks, measures, preferences, choices, behaviors, and instrument features precisely. Do not invent exclusion examples, attention checks, consent procedures, or analysis parameters to make reporting look complete; surface missing author information separately.
