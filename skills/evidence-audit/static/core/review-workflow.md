# Review responsibilities

## Authority and route

Review the current completed manuscript without new project setup. Projects use the current approved manuscript, not old imports, pending candidates or fragments mistaken for an export. Reuse version/scope confirmation; resolve conflicts. Approval is not scientific validation.

Do not fill omissions in the manuscript from memory or criticize removed claims. Profiles are background; no second profile or repeated positioning. Reuse valid journal context, sources and extraction. Report conflicts without overwriting state. Without a target, limit journal-specific conclusions.

## Depth

Use the entrypoint's screening/full/deep/incremental distinctions. Honor explicit scope/risk limits; reuse evidence, not verdicts.

## Delivery

Report findings, strengths and limits; distinguish errors, gaps and defensible choices. Test alternatives; withdraw refuted objections. Stop at feedback; later editing clarifies scope only if missing. Agreement is not execution. Never hide contrary results or promise acceptance.
