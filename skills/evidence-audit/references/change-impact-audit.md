# Change-impact audit

Use when an apparently local edit may alter the paper-wide evidence chain.

```text
project state and terminology ledger
→ targeted heading, variable, number, statistic, and claim search
→ context around matches
→ related sections
→ full manuscript only when coverage remains uncertain
→ synchronization list
→ user decision
```

The synchronization list considers title, abstract, keywords, introduction end, hypotheses, methods, results, study transitions, discussion, limitations, conclusion, tables, figures, captions, and supplements. Include only locations plausibly affected by this change.

Record read scope separately from proposed write scope. This module never writes. A broader read does not approve a broader edit.
