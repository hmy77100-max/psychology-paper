# Revision options within review

Organize advice that the model develops; do not replace academic reasoning with a decision tree. Use the existing findings, canonical issue IDs when available, evidence notes and contribution assessment. Do not repeat source retrieval or invent a persistent plan. An issues-only request does not need this expansion.

For each consequential recommendation, provide the relevant parts of this compact contract:

- Issue(s) addressed and intended benefit; what remains unresolved.
- Claims/strengths preserved, claims narrowed or changed, and the evidence needed for a stronger claim.
- Action type: clarify/report existing material, adjust framing, inspect existing outputs, propose new analysis, collect new evidence, or consider a different target.
- Feasibility: known resources, approximate effort with assumptions, uncertainty and dependencies. Do not invent precise cost, duration or acceptance benefit.
- Affected manuscript locations (inspected versus potential) and any decision needed from the author.

Present alternatives only when they represent meaningful choices. One adequate route is enough; do not manufacture a fixed number or force every problem toward an experiment. Recommend a preferred route with reasons under the author's stated goals and constraints. If no credible route can support the desired claim, say so rather than dressing an unresolved scientific problem as wording polish.

Experiments, additional analyses, target changes and alternative arguments are all allowed recommendations. Explain the question each would answer, conditions for usefulness, resources and remaining limits. A stronger but currently infeasible route may be described as contingent/future work; do not make it the only actionable choice when a bounded honest contribution remains possible. If a missing resource fact changes the choice materially, ask only that fact and continue independent advice.

Sequence by dependencies and publication impact, not by a universal checklist: verify uncertain scoring before changing conclusions that depend on it; resolve claim support before polishing contribution language. Consolidate actions shared by several findings. Preserve unresolved and deliberately held issues as such; a plan or promise is not inspected resolution evidence.

Example: a cross-sectional association described as a mechanism can support a route that narrows the claim and aligns dependent passages, preserving the association contribution but leaving causality untested. A proposed experiment is a separate stronger-evidence route with design/resource needs and uncertain outcome. Changing journal alone cannot repair the causal overclaim.

Return a concise recommended sequence plus meaningful alternatives and unresolved decisions. This is review advice, not manuscript replacement text or execution. Generic assent does not adopt a target/stance, resolve an issue or authorize edits. For a later explicit editing request, reuse a stated scope; otherwise ask full-manuscript versus targeted revision, then use the existing writing route. Analysis execution follows its own authorization route. No automatic cross-module handoff or state mutation.
