# Manuscript profile schema

Use these fields:

- `psychology_branch`
- `article_type`
- `paper_and_design_tags`
- `core_question`
- `contribution_type`
- `evidence_types`
- `evidence_ceiling`
- `intended_readers`
- `strongest_evidence`
- `largest_risk`
- `completion_state`
- `journal_directions`

Every field must be derived from the manuscript or author-confirmed information. Mark unresolved fields rather than filling them with a generic psychology template.
