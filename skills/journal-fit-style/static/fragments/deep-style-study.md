# Deep style study

Use this mode after the target journal is confirmed. Read 2–3 highly comparable recent articles by default. Observe introduction logic, theory-to-hypothesis transitions, multi-study progression, treatment of nonsignificant or inconsistent findings, discussion organization, claim verbs, figures/tables, and supplement placement.

Compare the articles. Record stable patterns, variable choices, and conflicts. Expand beyond three only when conflicting evidence prevents a useful conclusion. Translate observations into manuscript-specific revision implications without imitating sentences.
