# Routing and state recovery

- Missing authoritative source: stop and ask which file governs the task.
- Conflicting manuscript or analysis sources: preserve all roles and ask which one is authoritative.
- Uncertain evidence impact: route to `evidence-audit` rather than directly to writing.
- Missing file: report the exact missing path; do not search unrelated directories.
- Intentional hold: retain it without repeated prompts unless it blocks the requested action or requested risk review.
- Later-stage request: state the unavailable stage and preserve a minimal handoff; do not simulate completion.
- Invalid project state: report validator output and the shared rule ID; do not auto-correct scientific decisions.

Stage 1A never attempts manuscript recovery because it never mutates a manuscript.
