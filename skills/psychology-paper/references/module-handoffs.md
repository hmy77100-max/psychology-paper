# Module handoffs

Read [the minimal handoff schema](../../.shared/schemas/minimal-handoff.md). Pass paths and exact locations when the receiving module can read the source. Never transfer the full conversation, rejected alternatives, unrelated sections, or a repeated journal profile.

Every handoff names exactly one primary module, any bounded support modules, and a stop condition. Include only approved constraints and the current evidence ceiling. A support module returns its narrow result to the primary module; it does not take ownership of the task.
